# ADR 0045 — GLM 5.2 is the synthesis/critic default; the cost A/B closes

**Date:** 2026-08-30 · **Phase:** 7 · **Status:** accepted
· **Relates to:** ADR 0001 (the routing defaults this supersedes for two roles),
ADR 0014 (the provider-agnostic router that made the swap a config change)

## Context

`synthesis` and `critic` are the two high-stakes reasoning roles — the draft
answer and the quality gate. ADR 0001 set them to `claude-opus-4-8`, and Phase 7
Deliverable 1 was scheduled to decide the cheaper routing with a live eval
experiment (Opus vs `claude-sonnet-5` vs open-model challengers). The system has
run on the GLM 5.2 challenger arm (`z-ai/glm-5.2-20260616`) since then, and the
A/B eval runs that the decision needed are now complete.

## Decision

**GLM 5.2 (`z-ai/glm-5.2-20260616`) is the default for `synthesis` and
`critic`.** The cost A/B is closed. The planned live `claude-sonnet-5` synthesis
experiment (Phase 7 Deliverable 1) is dropped: the experiments needed to choose
the route have been run.

`eval_judge` stays on `claude-sonnet-5`. It is the measuring stick, not a
production role, and judging the answer path with the model under test would be
circular. This decision does not touch it.

## Rationale

The metrics held at far lower cost — the blueprint's own earn-it rule
(complexity and cost both justified against the output). GLM 5.2 clears the
exit-gate floors on the gold set: the standing accepted baseline,
`eval/baselines.json` (`agent-20260813-174221`), reads `grounding_rate` 0.980,
`hallucination_rate` 0.000, every floor met. It does so at a fraction of the
Anthropic price:

| Role model | $/M input | $/M output |
|---|---|---|
| `claude-opus-4-8` | 5.00 | 25.00 |
| `claude-sonnet-5` | 3.00 | 15.00 |
| `z-ai/glm-5.2` | 0.95 | 2.98 |

The per-arm metric table and the cost-per-question math land in the Phase 7 cost
note (`docs/decisions/model-routing-and-cost.md`, Deliverable 1); this ADR
records the routing decision that note concludes to.

## Consequences

`src/fie/config.py` already routes both roles to GLM 5.2, so nothing on the
answer path changes and no baseline is invalidated. The stale framing —
"challenger arm", "revert to Sonnet", "production default is Opus" — is corrected
in `config.py`, ADR 0001, `plans/00-overview.md`, `plans/phase-7-cost-and-rigor.md`,
and `CLAUDE.md`. Because no code changed, the exit-gate metrics are unchanged.

# Evaluation data (Phase 3, workstream C)

Two eval layers, attributing failures to **retrieval vs reasoning**
(blueprint §5/§6). Code lives in `src/fie/eval/` (importable, so the
runners below work as `uv run` scripts); this directory holds the
versioned datasets, the accepted baselines, and generated reports.

## Files

- `retrieval_queries.jsonl` — 50 authored retrieval-eval queries, labeled
  at **(ticker, form, section, period)** granularity (stable across
  re-chunking; a retrieved chunk counts as relevant when its section
  matches). `label_status: "seed"` until hand-verified — **the operator reviews**,
  then flips entries to `"verified"`. `uv run eval-seed` generates extra
  candidates into `retrieval_queries.candidates.jsonl` from the ingested
  corpus.
- `gold_set.jsonl` — 30 end-to-end analyst questions (8 single-company
  numeric, 6 multi-period trend, 6 cross-company, 6 qualitative, 4
  **unanswerable-from-corpus** — the system must decline/retract, not
  invent). Numeric expected facts reference the XBRL store by concept +
  period; the expected *value* is pulled from the facts table at eval time,
  never hand-copied.
- `verifier_claims.jsonl` — generated by `uv run eval-seed` after ingest:
  real claims rendered from XBRL facts (`grounded` by construction) plus
  systematic perturbations (digits changed, periods shifted, scale shifted,
  sentiment inverted → `unsupported` by construction). Measures the
  verifier itself, per claim type — the measurement behind the verifier
  model-escalation decision (3.5).
- `baselines.json` — the accepted metric numbers. `uv run eval-agent`
  exits non-zero when any gated metric drops below its baseline; a run's
  numbers are accepted with `--write-baseline`. Null = no baseline yet.
- `reports/` — timestamped JSON/markdown outputs (gitignored except kept
  decision reports).

## Runners

```
uv run eval-retrieval --embedding both --rerank both   # the benchmark (ADR 0011)
uv run eval-agent                                      # gold set → §6 metrics + gate
uv run eval-agent --limit 3 --skip-judge               # cheap smoke
uv run eval-seed                                       # regenerate derived sets
```
